Cara Kerja Auto-Update:
  1. Setiap kali karyawan membuka aplikasi mobile, sistem akan mengecek versi ini secara otomatis.
  2. Jika versi di server lebih tinggi, pop-up dialog update akan langsung muncul menanyakan apakah ingin memperbarui.
  3. Jika pengguna memilih "Perbarui Sekarang", APK akan langsung diunduh dan dipasang di dalam aplikasi.
Rilis Versi Aplikasi Baru
Format X.Y.Z (harus lebih tinggi dari versi saat ini)

Unggah file app-release.apk hasil build Flutter. Jika dikosongkan, link download default akan tetap digunakan.
